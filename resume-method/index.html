AI resume method

One honest CV,
a tailored page for every job

How career-ops, the most-starred AI resume project of 2026, turns a single source CV into a designed, ATS-readable PDF for each job description, with checks that keep every line true.

中文摘要

目前最火的 AI 做简历方式是开源项目 career-ops（GitHub 约 7.8 万星，MIT 许可，2026 年 4 月爆火）。它跑在 Claude Code 等 AI 命令行里：你只维护一份真实的主简历 cv.md，每贴一个职位描述（JD），AI 就提取关键词、找出你缺的技能、重排经历、改写摘要，然后输出一份结构化 JSON，再由脚本套进设计好的 HTML 模板，生成 PDF。

核心三条：只改写真实经历、绝不编造（有代码级的事实校验）；单栏 ATS 友好排版；固定的视觉设计（Space Grotesk + DM Sans 字体、青到紫渐变线）。下面是完整步骤、数据结构、设计规范和来源。

Inputs and outputs

What goes in, what comes out

You keep

cv.md, the single source of truth: every role, title, date and number, written once and kept honest. Optional article-digest.md for proof points such as talks and articles.

You set once

config/profile.yml: name, contact, headline, target roles, page size (A4, Letter or auto by country), photo on or off, default template.

Each time

A job description, pasted as text or a link. That is the only per-job input.

You get

A tailored cv.html and cv.pdf, a list of skill gaps, a keyword-coverage score, and optionally a plain ATS copy and a cover letter.

The method

Ten steps from job post to PDF

  1. Read the source CVLoad cv.md. Nothing in the output may come from anywhere else.
  2. Save the job descriptionWrite the JD to its own file first, so it is archived even after the posting closes.
  3. Pull 15–20 keywordsExtract the exact vocabulary the employer uses for skills, tools and outcomes.
  4. Sort skills into three groupsA script compares JD requirements with cv.md: existing (already named), supported (shown in your bullets but not named yet) and gap (no trace). Gaps are shown to you before anything is written, and never filled in.
  5. Pick language, paper and role typeUS or Canada uses Letter, everywhere else A4. Detect the role archetype to choose the framing.
  6. Map the recruiter's doubtsList what a reviewer would worry about for this job and which real evidence answers each doubt.
  7. Tailor, never inventRewrite the summary with JD keywords, choose the 3–4 most relevant projects, reorder bullets so the strongest match comes first, and build a 6–8 tag competency grid from existing and supported skills only. Roles stay in reverse-chronological order.
  8. Write a JSON payload, not HTMLThe AI emits compact structured data (schema below). A script owns all markup and escaping, which cuts tokens and stops broken layouts.
  9. Run the gatesTitle check: no job title may drift from cv.md. Structure check: no lost company details or reordered roles. Fact gate (hard stop): any number or claim not found in your sources blocks the PDF.
  10. Render and reportFill the chosen HTML template, print to PDF with headless Chromium, warn past two pages, then report the path, page count, keyword coverage and remaining gaps.

Optional passes: a hiring-manager audit (a separate agent role-plays the reviewer and marks each bullet keep, cut or rewrite) and an ATS copy (same facts, competency tags folded into a plain Skills line for pasting into application forms).

The design

One clean column, two typefaces, one gradient

Visual spec

  • Headings: Space Grotesk 600–700; body: DM Sans 400–500 at 11px, line height 1.5. Both fonts are OFL and self-hosted.
  • Name in Space Grotesk 24px bold, then a 2px gradient line, then the contact row.
  • Section headers 13px, uppercase, letter spacing 0.05em, in the cyan primary.
  • Company names in the purple accent.
  • Margins 0.6in on pure white.

Section order, built for a six-second scan

  1. Header: name, headline, gradient line, contact, portfolio
  2. Professional Summary: 3–4 keyword-dense lines that say which role and why this one
  3. Core Competencies: 6–8 keyword tags
  4. Work Experience, newest first
  5. Projects, the 3–4 most relevant
  6. Education and Certifications
  7. Skills: languages and technical

Templates that ship

Base, modern, compact, executive, leadership, a "Jake"-style classic, an ATS-plain variant, a Chinese minimal template (zh-minimal, Simplified Chinese fonts and strict CJK line breaks) and LaTeX versions including a CJK one. Setting lang to zh-CN in the payload switches fonts and line breaking.

The rules

ATS rules and honest keywords

Parseable by machines

  • Single column, no sidebars or nested tables
  • Standard headers: Professional Summary, Work Experience, Education, Skills, Certifications, Projects
  • Empty sections disappear, header included
  • No text inside images, nothing critical in page headers or footers
  • Real selectable UTF-8 text
  • Keywords spread across the summary, the first bullet of each role, and Skills
  • No hidden text, white-font tricks or stuffing

Reword, never add

Use the employer's words for experience you really have. Examples from the project:

  • "LLM workflows with retrieval" → "RAG pipeline design and LLM orchestration workflows"
  • "collaborated with team" → "stakeholder management across engineering, operations and business"

Bold (**…**) marks the one result a recruiter should catch, such as "cut latency to 120 ms". Bold reorders attention; it never adds a claim.

The data

The JSON payload the AI writes

The AI's whole job ends here. A script fills the template from these keys and fails loudly on a missing required field or a misspelt section name.

{
  "lang": "en",                // "zh-CN" switches to Chinese fonts
  "page_format": "a4",         // "letter" for US / Canada
  "candidate": {
    "name": "", "title": "", "email": "", "phone": "",
    "location": "",
    "linkedin":  { "url": "", "display": "" },
    "portfolio": { "url": "", "display": "" },
    "photo": ""                // empty = no photo (US/UK); set for DACH
  },
  "summary": "3–4 lines with JD keywords, true to cv.md",
  "competencies": ["6–8 keyword phrases"],
  "experience": [{
    "company": "", "role": "", "location": "",
    "context": "one line about the company",
    "dates": "June 2022 - Present",
    "bullets": ["strongest JD match first, **key result** in bold"]
  }],
  "projects":       [{ "name": "", "url": "", "tech": "", "description": "" }],
  "education":      [{ "title": "", "org": "", "year": "", "description": "" }],
  "certifications": [{ "title": "", "org": "", "year": "" }],
  "awards":         [{ "title": "", "org": "", "year": "" }],
  "skills":         [{ "category": "Languages", "items": "English, Mandarin" }]
}

Required per entry: company + role for experience, name for projects, title for education, certifications and awards, items for skills.

Using it

How to run it

The project installs with one command and then sets itself up by chatting: it asks for your CV, profile and target roles.

npx @santifer/career-ops init
cd career-ops
claude

Then paste a job link or JD text, or ask for the pdf mode on a role you have already evaluated. It needs Node.js and, for PDFs, Playwright Chromium. It drafts and never submits or sends anything; you read every CV before it goes out.

Without installing anything, the same method works by hand with any AI chat: keep an honest master CV, give it the JD, ask for the skill-gap split first, then the tailored JSON above, then check every number against the master CV before laying it out.

The resume maker on 花屿 builds that prompt for you from what you have done and the job you want.
